# Flutter Linux Desktop Parity Matrix

This matrix tracks the gap between the current Electron desktop reference and the Flutter Linux rewrite. Phase 6 Android/iOS work should not start until the required Linux rows are implemented and verified.

Status values:

- `Done`: implemented and covered by a local verification command.
- `Partial`: implemented in part, but either not feature-complete or not fully verified.
- `Open`: not implemented in Flutter yet.

## Required Completion Gate

Before marking Phase 5.5 complete:

- Every required row above must be `Done`, or explicitly documented as an accepted desktop difference.
- Flutter tests must include at least one stable app-shell or widget-level test for each required workflow.
- Service-level parity tests must compare exported backup snapshots for migration-critical fields.
- `flutter build linux --debug` must pass after the full parity set lands.
